# 世界陣取りクエスト — セットアップ

世界地図をみんなで塗り合う、リアルタイム陣取り×地理クイズゲームです。

- 国をタップ → **国旗クイズ**（約75%）を中心に、首都・特色文化の問題に正解すると占領
- 1つのマップを**クラス全員で共有**（ほかの人の領地もうばえる）
- 塗った数・つなげ塗り・州制覇などで**ボーナス**
- 地図は world-atlas（Natural Earth）の外部データを **three.js** で描画（手書きSVGなし）
- スマホ・タブレット・PC どの画面幅でも動作
- 記録は**まなびの基盤**に送信

### 出題のしくみ

| 種類 | 割合 | 例 |
|---|---|---|
| 🚩 国旗 | 約75% | 「ブラジル」の国旗はどれ?（4つの国旗から選ぶ） |
| 🏛 首都 | 約19% | 「アイルランド」の首都はどこ? |
| 📚 ちしき | 約6% | アマゾン川流域で、開発によって問題となっていることは? |

- 選択肢の**まちがい3つは同じ州の国**から選ばれるので、当てずっぽうが効きにくくなっています
- **国をタップしても国旗は表示されません**（「？ひみつ」と出ます）。国旗クイズの答えになってしまうためです。正解して占領すると、国旗と首都が見られるようになります
- 「ちしき」を持つ国では、**人の領地をうばうときだけ**その問題が優先して出ます（うばうのは難しめ）

## 1. まず動かしてみる（5秒）

`index.html` をダブルクリックして開き、「📴 ひとりで練習」を選ぶだけで動きます
（インターネット接続は必要です。地図・国旗・ライブラリ・フォントをCDNから読み込むため）。

**この端末では設定ずみです。** `index.html` の `endpoint` に Apps Script のURLが入っていて、
接続確認（`?mode=ping` → `つながっています`）も通っています。「🌐 みんなで対戦」がそのまま使えます。

## 2. みんなで対戦できるようにする（約10分）

まなびの基盤と同じ Apps Script 方式ですが、**通信回数が多いため基盤とは別のスプレッドシートを新しく作ってください。**

1. Googleドライブで新しいスプレッドシートを作る（名前:「世界陣取り」など）
2. **拡張機能 → Apps Script** を開き、中身を全部消して `code.gs` を貼りつける
3. 先頭の2つの合言葉を自分で決めた文字列に書きかえて保存
   ```js
   var WRITE_TOKEN = 'chiri-write-2026';   // 生徒アプリが使う
   var ADMIN_TOKEN = 'chiri-admin-2026';   // 先生だけが使う（リセット用）
   ```
4. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 出てきた `https://script.google.com/macros/s/…/exec` をコピー
6. `index.html` の先頭にある設定に貼る
   ```js
   window.GAME_CONFIG = {
     endpoint: 'ここに手順5のURL',
     token:    'WRITE_TOKEN と同じ文字列',
     pollMs:   6000
   };
   ```

動作確認: URLの後ろに `?mode=ping` を付けてブラウザで開き、`つながっています` と出ればOK。

> code.gs を直したら、毎回 **デプロイ → デプロイを管理 → 鉛筆 → 新バージョン → デプロイ** が必要です（まなびの基盤と同じ）。

### 「まなびの基盤にもどる」ボタンについて

画面左上に表示されます。左上はこのボタンの場所として空けてあり、スマホ幅ではスコア表示を
右に寄せて重ならないようにしています。

**このゲームは自前でもボタンを用意しています。** 理由は次のとおりです。

ハブの `manabi-connect.js` には「ハブ自身にはボタンを出さない」判定がありますが、
これが**前方一致**になっています。

```js
if (global.location.href.indexOf(HUB) === 0) return;
```

そのため、このゲームを `ManabiBox/world-conquest/` のように**ハブと同じフォルダの中**に置くと、
URLがハブのURLで始まるせいで「ハブ本体だ」と誤判定され、ボタンが付きません。
`game.js` の `addBackButton()` が、まだ無いときだけ自前で用意して補っています
（`id` を `manabi-back` でそろえてあるので、二重には出ません）。

#### ハブ側を直したい場合（任意）

`ManabiBox/manabi-connect.js` の上の1行を、次のように変えると根本的に直ります。
今後どのゲームをハブのフォルダ内に置いても、ボタンが正しく出るようになります。

```js
var here = global.location.href.split('#')[0].split('?')[0].replace(/index\.html$/, '');
if (here === HUB.replace(/index\.html$/, '')) return;   // ハブ本体のときだけ出さない
```

それでも出ないときは、次を確認してください。

- 校内ネットワークが `backtree-create.github.io` をブロックしている（3行のスクリプトが読めていない）
  → この場合も自前ボタンは出ます。リンク先は `MANABI_CONFIG.hubUrl` が無ければ `../` になります
- ハブ側の `config.js` で `backLink: false` になっている（意図的に消す設定）

`?manabidebug=1` を付けて開くと、ハブ側の判断理由がコンソールに出ます。

## 4-2. 使えない時間帯

`index.html` の先頭で、**使えなくする時刻**を決めます。

```js
  blockFrom: '17:00',   /* この時刻から */
  blockTo:   '08:30'    /* この時刻まで 使えない */
```

初期設定は **17:00〜翌8:30が使用不可**（つまり学校にいる時間帯だけ使える）です。
`17:00 → 翌8:30` のように**日をまたぐ指定**もそのまま書けます。
両方を `''`（空）にすると、いつでも使えます。

| 場面 | どうなるか |
|---|---|
| 使えない時間に開いた | スタート画面が赤くなり、「⏰ 17:00〜8:30 は使えません。8:30 になったら、また来てね!」と出てボタンが押せません |
| 遊んでいる途中で 17:00 になった | 地図が止まり、リザルト（スコア・占領数・正答率・州ごとの内訳）が出て、記録が自動でまなびの基盤に送られます |
| 終了10分前 | 画面上の「のこり」が秒読みに変わり、10分前・5分前・1分前に知らせます |
| 8:30 になった | スタート画面のボタンが自動で押せるようになります（開いたままでも切りかわります） |

### 先生が時間外に確認したいとき

URLのうしろに `?free=1` を付けると、その画面だけ制限が外れます。

```
https://backtree-create.github.io/ManabiBox/world-conquest/index.html?free=1
```

**生徒には教えないでください。** この制限は端末のブラウザの中で動く「やりすぎ防止の目安」で、
時計を変えたり、ページのソースを読んだりすれば回避できます。厳密な締め出しではありません。

端末の時計を基準にしているので、端末の時刻がずれていると判定もずれます。

## 5. 授業での使い方

1. 先生がルーム名を決めて板書する（例: `3-2`）
2. 生徒はニックネームとルーム名を入れて「🌐 みんなで対戦」
3. 終わったら 📤 ボタンで記録送信
4. 次のクラスの前に、先生がブラウザでリセットURLを開く:
   ```
   <AppsScriptのURL>?mode=reset&room=3-2&admin=ADMIN_TOKEN
   ```

### ルール（生徒向け・ゲーム内❓にも表示）

- 国をタップ → 国旗クイズなどに正解で占領（+100）
- ⚡7秒以内 +30 ／ 🔥連続正解 最大+100 ／ 🧩となり合わせ +50
- ⚔️人の領地をうばうと +100（ただし占領直後45秒は保護）
- 🏅5か国ごと +200 ／ 🌏同じ州で5か国ごと +300 ／ 👑州制覇 +1000
- 誤答するとその国に30秒再挑戦できない（4択の総当たり防止）

## 気をつけること・制限

- **本名は入れさせない**（ニックネームのみ。基盤と同じ運用）
- 共有マップは約6秒ごとに更新されます（完全な同時反映ではありません）。
  サーバーの返事には1〜3秒かかるため、自分の占領が届く前に古い状態の返事が返ってくることがあります。
  そのまま映すと「取り合っていないのにうばわれた通知が出る」ので、
  通信ごとの通し番号で古い返事を捨て、返事待ちの占領は画面上で保つようにしています
- **スコアはサーバー側に貯まります。** 途中でリロードしても、入り直したときに
  サーバーに残っている自分の点を引きついで続きから遊べます。
  点が下がることはありません（0から始めたいときはルームをリセットしてください）
- **国コードは3けたで扱います。** スプレッドシートは `004` を数値の `4` として覚えてしまうため、
  読みなおすときに3けたへそろえています。ここをそろえないと、
  オーストラリア・ブラジルなど**コードが100番より小さい国の領地が消えます**
- Apps Script の無料枠の関係で、**同時利用は1〜2クラス程度**を想定しています。
  学年一斉で使う場合は、クラスごとに別ルーム名にし、時間をずらすと安全です
- 地図データ（jsDelivr）・国旗画像（flagcdn.com）・three.js（cdnjs）を読み込むため、
  校内ネットワークでこれらのドメインがブロックされていると動きません。
  うまく表示されないときは各URLに直接アクセスして確認してください
- 占領記録はスプレッドシートの `log` シートに残るので、あとから集計もできます

## クイズを増やすには

`trivia.js` に同じ形式で足すだけです。

```js
"504": [   // モロッコ（ISO数字コード = countries.js のキー）
  { q: "問題文", c: ["正解", "まちがい1", "まちがい2", "まちがい3"] }
],
```
